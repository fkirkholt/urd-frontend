This is the frontend for
[Urðr](https://github.com/fkirkholt/urd-backend)

## Installation

Install the [backend](https://github.com/fkirkholt/urd-backend) first
into folder 'urdr', and clone this repository into folder 'static':

``` bash
> cd urdr
> git clone https://github.com/fkirkholt/urd-frontend static
> cd static
> yarn install
> yarn build
```

For development, run `npm start` instead of `npm run build`.
